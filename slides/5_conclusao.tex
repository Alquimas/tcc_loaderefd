\section{Conclusões e Trabalhos Futuros}

\begin{frame}{Conclusões}
  \textbf{No fim, nossa equipe conseguiu:}
  \begin{itemize}
    \item Desenvolver um \textit{ETL} dinâmico validado para arquivos EFD ICMS IPI.
    \item Executar com sucesso o desacoplamento entre lógica de código e regras de negócio por meio de contratos em JSON.
    \item Garantir a integridade do \textit{pipeline} por meio de \textit{round-trip}.
    \item Descobrir limitações no modelo atual que podem ser usadas para refinar este ou outros projetos de ETL.
  \end{itemize}
\end{frame}

\begin{frame}{Trabalhos Futuros}
    \textbf{Delimitamos como possíveis trabalhos futuros:}
    \begin{itemize}
      \item \textbf{Otimização de Carga de Dados:} Uso de \textit{staging tables} e \textit{bulk inserts} para resolver o gargalo encontrado.
      \item \textbf{Testes de Estresse e Escala:} Realizar experimentos quantitativos em ambientes de carga extrema.
      \item \textbf{Expansão do Modelo:} Aplicação da arquitetura modelada neste trabalho para outros documentos textuais complexos e voláteis.
    \end{itemize}
\end{frame}
